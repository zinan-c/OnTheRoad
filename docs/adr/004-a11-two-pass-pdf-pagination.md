# ADR-004: A11 PDF 采用固定字体与两遍目录排版

- 状态：Accepted
- 日期：2026-07-26
- 决策范围：A11 PDF Spike；后续 F04/F05 的输入约束

## 背景

A11 必须用可重复实验关闭四类风险：中文字体回退、50 页复杂分页、静态地图资源缺失，以及目录数字与最终物理页不一致。单遍 HTML 打印无法在目录渲染前可靠知道最终锚点页；依赖开发机系统字体也不能在 CI/生产镜像中复现。

## 决策

1. PDF Worker 固定使用 Noto Sans CJK SC 2.004。字体、OFL-1.1 许可证和 SHA-256 一并入库；生成器在启动打印前校验字体 SHA，不允许静默回退系统字体。
2. 使用 Playwright Chromium 的专用打印 HTML，等待 `document.fonts.ready` 和所有图片 `decode()`；资源等待超时即失败，并确保目标成功 PDF 不存在。
3. 精确目录使用两遍渲染：
   - 第一遍渲染与最终文档等高的目录占位页及正文；
   - 逐页提取稳定锚点，得到最终物理页；
   - 回填目录数字并第二次渲染；
   - 再次逐项比较目录数字与最终 PDF 的锚点物理页。任一不一致即删除成功产物并失败。
4. 地图使用本地固定 PNG，不依赖公网；PDF 同时包含可见 attribution。
5. Chromium 从仓库依赖 `@playwright/test` 解析，默认使用 `chromium.executablePath()`；CI 必须安装与依赖版本匹配的浏览器。`OTR_A11_CHROMIUM_PATH` 仅用于显式选择已安装浏览器。默认不关闭 Chromium sandbox；只有隔离运行环境明确要求时才允许设置 `OTR_A11_DISABLE_CHROMIUM_SANDBOX=1`。
6. TC-A11-03 将全部物理页转为 PNG，逐页检查尺寸、非空白程度和安全边缘，并保留逐页 JSON、全页 contact sheet 及代表页证据。

## 结果

该方案在固定环境中生成 50 页 A4 横向和纵向 PDF；中文可搜索/提取，固定字体已嵌入；48 个目录项逐项匹配物理页 3–50；资源超时不会留下成功产物；纵向 50 页逐页视觉检查无空白或边缘裁切。

## 后果

- 正式 PDF 模板须保留稳定锚点和目录占位页尺寸；目录回填后仍必须做最终物理页复核。
- 构建镜像须安装 Chromium、Poppler，并校验字体与许可证哈希。视觉回归环境还需要 ImageMagick。
- PDF 的确定性不以二进制字节完全相同为前提；验收依据是固定输入下的结构、文本、页码、字体、资源和逐页视觉指标。
- 两遍渲染增加一次 Chromium 打印成本，但优先保证目录准确性。

## Plan B

若后续真实模板的目录回填会改变分页，则保持相同验证门禁并升级为迭代排版，直到目录页集合与正文锚点页收敛；仍不收敛时拆分为固定目录页块与正文 PDF 后再合并。任何 Plan B 都不得交付已知错误页码。
