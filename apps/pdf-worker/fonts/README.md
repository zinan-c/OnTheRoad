# PDF worker fonts

A11 vendors fixed Noto Sans CJK SC 2.004 as
`NotoSansCJKsc-Regular.otf`. The spike deliberately rejects operating-system
fallback fonts.

The approved artifact's upstream source, version, copyright, OFL-1.1 license,
and SHA-256 are recorded in `FONT_MANIFEST.json`. The upstream license is
vendored as `OFL.txt`. CI must verify both checksums before using the font.
